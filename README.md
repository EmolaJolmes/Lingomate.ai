# LingoMate AI

## AI Language Learning Assistant

LingoMate AI is a responsive web application that helps students learn new languages through AI-powered lessons, quizzes, conversation practice, and vocabulary management.

It is designed for students, self-learners, travelers, and anyone wanting a simple way to practice a new language without creating an account.

---

## Real Problem Solved

Many language-learning platforms require subscriptions, user accounts, or fixed learning paths. LingoMate AI provides instant personalized learning content using artificial intelligence without requiring users to register.

## AI Feature

The application uses integrated AI to generate personalized language lessons, quizzes, and conversation practice based on the user's selected language, topic, and difficulty level.

The AI adapts its responses according to the user's input, providing dynamic educational content.

## Prompt Used

You are an AI language tutor.

Your role is to help users learn languages through personalized lessons, quizzes, and conversation practice.

Generate educational content based on the user's selected language, topic, and proficiency level.

Explain grammar clearly, introduce useful vocabulary, provide example sentences, create appropriate quiz questions, and engage in realistic conversations.

Always be encouraging, accurate, and supportive. Format responses using clear headings and bullet points. Avoid harmful or inappropriate content.

---

### AI Instructions

The AI is instructed to:

- Generate beginner to advanced lessons
- Create quizzes with appropriate difficulty
- Simulate realistic language conversations
- Encourage language learning
- Explain vocabulary clearly
- Keep responses educational and easy to understand

## How to Run

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Install dependencies.

```bash
npm install
```

3. Start the development server.

```bash
npm run dev
```

4. Open the local URL shown in the terminal.
